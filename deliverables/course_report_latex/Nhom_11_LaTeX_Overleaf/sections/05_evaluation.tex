\section{Implementation and Evaluation Plan}
\subsection{Environment and Artifact Organization}
The implementation is written in Python and uses AgentDojo Workspace v1.2.2 at commit \texttt{089ed468cf3e}. The historical reproduction environment pins CPython 3.12.13, Pydantic 2.11.4, and PyYAML 6.0.2. Existing state fixtures also depend on the Windows cp1252 default encoding with Python UTF-8 mode disabled. This is a reproduction constraint for the current data, not a recommendation to use cp1252 for new data.

The guard and migration adapter are in the TaskFileScope module; the source preflight runs the authorized operation sequence through ToolsExecutor. The historical name-only control remains in the v2 manifest and validator. The TaskFileScope amendment adds the resource schema; its report acceptance path is being strengthened and is not a complete research result.

F/$v1$ does not understand the new resource path and therefore denies append. M/$v1$ interprets the resource correctly and allows append to the authorized file. This matches the predicted utility loss for a frozen policy. It does not demonstrate a security regression: the task grants no deletion permission under either version, so this slice cannot distinguish the primary harmful-effect hypothesis.

An integration check with a fake OpenAI-compatible server ran search and append calls through the fresh capture process: F/$v1$ preserved state when denying the call, while M/$v1$ changed state after append. This is evidence that the execution and evidence-collection path works. A fake server cannot show that a model resists prompt injection.

The regression suite at snapshot \texttt{e678ea2} recorded 144 passing tests with no failures or skips. This count applies to that snapshot; it does not validate research changes made afterward. The tests cover metadata, traces, reset behavior, missing evidence, and request retries. Test counts are not a measure of security effectiveness.

\subsection{Reproduction and Acceptance Criteria}
In the repository's pinned environment, run the TaskFileScope source preflight and the corresponding amendment integration tests. The accompanying LaTeX README provides paths and PowerShell commands. Compiling the report does not require the AgentDojo environment or an API key.

Component acceptance requires that unauthorized calls do not reach the native executor; denials do not change typed state; F does not change its policy across contracts; M changes only the declared decoder; and utility is scored independently. Provider failures, reset errors, and missing traces must remain in the planned sample rather than being removed to improve results.

\subsection{Next Experimental Design}
The research phase needs a treatment in which an authorization change can expose a harmful effect. F must not be weakened to manufacture a desired result. For each case, hold the model snapshot, task, carrier, and reset constant, and run F/M under both $v0$ and $v1$. Keep the attack endpoint separate from default-control utility, retain all four transitions, and record reasons for unscorable cases.

With sufficient data, report the paired risk difference, source-task-clustered bootstrap intervals, and McNemar tests where the independence assumptions are appropriate. The research plan calls for at least three model snapshots, held-out carrier checks, and independent reproduction. No dataset meeting these gates is reported here.
