\section{Related Work}
AgentDojo provides a stateful environment for evaluating agents under prompt injection and measures both security and utility \cite{debenedetti2024}. This project uses it as a source of tasks and tools. A successful call to a simulated tool verifies integration only; agent evaluation requires actions generated by the model.

InjecAgent studies indirect prompt injection in tool-integrated agents \cite{zhan2024}. It motivates distinguishing attack instructions in content from actions produced by the agent. This report does not treat a handwritten call sequence as equivalent to an episode in which a model reads a carrier and decides what to do.

CaMeL separates untrusted data from control flow and uses capability checks \cite{debenedetti2025}. Progent focuses on privilege control through policy \cite{shi2025}. Because authorization and runtime enforcement are established research topics, TaskFileScope serves here as a reference component for testing rather than a claim of a new protection principle.

The project focuses on measuring the same defense under two tool contracts. This is a testable evaluation question. The works summarized here are selected close references, not a complete systematic review, and do not establish the novelty of the research contribution.
